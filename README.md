# Бара. Сезон 5 — «Бара и близкие»

Интерактивное веб-приложение по книге «Бара. Сезон 5» — курс медитаций про капибару Бара, который впервые за курс смотрит не только на себя, но и на пространство между собой и близкими: раздражение, зависть, неудобную правду, обиду рядом с благодарностью, усталость, неприязнь, короткую связь.

**Живая версия:** _(вставь сюда ссылку после публикации на GitHub Pages, например `https://annavera2020.github.io/bara-season5/`)_

## О проекте

Семь уроков — семь типов близких: бабушка, брат/сестра, друг, родитель, тот, кто учится, сосед, случайный попутчик. Без глянца: не все встречи в сезоне тёплые с первой минуты — это тоже часть книги. Пользователь листает уроки, проходит упражнение на осознанность, отмечает практику дня, слушает аудио-гид и отвечает на вопросы вечера. Прогресс сохраняется локально (localStorage).

## Функциональность

- 12 экранов: обложка с оглавлением, пролог, 7 уроков, итог сезона, финальная практика, эпилог
- В каждом уроке — пять блоков: История → Непосредственное наблюдение → Практика дня → Аудио-гид → Вопросы вечера (4 вопроса)
- Блокировка кнопки «Дальше» до отметки выполненной практики дня
- Прогресс-трекер по всем урокам (кнопка ☰)
- Плеер аудио-гида для каждого урока (аудиофайлы подключаются отдельно, см. ниже)
- Текстовые поля с автосохранением ответов на вопросы вечера
- Адаптивная вёрстка (мобильная карточка / десктопный вид), поддержка светлой и тёмной темы
- Точка обрезки иллюстрации подобрана отдельно для каждого экрана — так, чтобы на узкой мобильной раскладке в кадре оставались персонажи, а не только фон

## Технологии

Один самодостаточный HTML-файл: HTML + CSS + vanilla JavaScript, без сборки и зависимостей. Иллюстрации встроены как base64. Шрифты — Newsreader, Karla, IBM Plex Mono (Google Fonts).

## Как добавить аудио-гиды

Плеер каждого урока ищет файл `audio/urok-<номер>.mp3` (например, `audio/urok-1.mp3` для урока 1 — «Бабушка»). Положи mp3-файлы с такими именами в папку `audio/` рядом с `index.html` — плеер заработает без правок кода.

## Запуск локально

Файл `index.html` можно открыть прямо в браузере — сервер не требуется.
